# 🎂 Festival de Bolos — Marília Bolos

Website institucional e promocional desenvolvido para a **Marília Bolos**, focado na apresentação do cardápio de bolos artesanais e divulgação das informações do **Festival de Bolos**.

---

## 🚀 Funcionalidades

- **Apresentação Atraente:** Secção inicial (*Hero*) com destaque para a confeiteira e efeitos visuais interativos de *hover*.
- **Cardápio de Bolos:** Exibição das especialidades (Bolo Matilda, Bolo Ninho c/ Morango, Bolo Pudim) com descrições detalhadas e apelativas.
- **Informações do Evento:** Data, horário e localização exata do Festival de Bolos com mapa interativo integrado do Google Maps.
- **Contacto Rápido:** Links diretos com mensagens personalizadas para o **WhatsApp** e direcionamento para o **Instagram**.
- **Design Responsivo:** Navegação fluida e adaptada para telemóveis, tablets e computadores.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica e acessível.
- **CSS3:** Estilização personalizada, Flexbox, CSS Grid e animações/efeitos de transição.
- **JavaScript (Vanilla):** Comportamentos interativos da página.
- **Google Fonts:** Tipografias *DM Sans* e *Playfair Display*.
